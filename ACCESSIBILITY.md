# Accessibility

This applies to every MELOPHOS repository that does not have its own `ACCESSIBILITY.md`. The platform's own statement, covering the lights, the hub, the Studio and the documentation, lives in [melophos/melophos](https://github.com/melophos/melophos/blob/main/ACCESSIBILITY.md) and takes precedence there.

## Documentation

Documentation across the organisation aims to:

- Use a real heading outline, so screen readers and the page outline can jump between sections.
- Use link text that says where the link goes, never "click here".
- Give images, diagrams and badges alt text. Write diagrams as Mermaid where possible, so their content is text.
- Show code, commands and output as text, never as screenshots.
- Never rely on colour alone: callouts carry a label such as Note, Tip or Warning.
- Use plain language, explaining a term where it first appears.

## Reporting a barrier

If anything in a MELOPHOS repository is hard to read or use, open a discussion on [melophos/melophos](https://github.com/melophos/melophos/discussions) describing what did not work and what would. Accessibility problems are treated as bugs.
