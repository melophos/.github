# Contributing

Thanks for taking an interest in MELOPHOS.

> [!IMPORTANT]
> All development happens in [melophos/melophos](https://github.com/melophos/melophos). The component repositories (`firmware`, `hardware`, `core`, `server`, `studio`, `client`, `profiles` and `docs`) are read-only copies published from it, so pull requests opened there cannot be merged.

The full guide, with the checks to run and the style rules, is [CONTRIBUTING.md in the monorepo](https://github.com/melophos/melophos/blob/main/CONTRIBUTING.md).

The quickest first contribution is an instrument profile for a keyboard or guitar that is not covered yet, see [profiles/README.md](https://github.com/melophos/melophos/blob/main/profiles/README.md).

More about the maintainer: [isaacadjei.me](https://isaacadjei.me).
